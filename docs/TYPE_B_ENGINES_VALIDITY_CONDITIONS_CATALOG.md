## 1. Epistemic Foundation & Strict 1-to-1 Code Bijection Invariant

Unlike **Tier 1 (Type A)** biophysical engines—which encode universal, invariant conservation laws of physics, chemistry, thermodynamics, and cross-taxa bioenergetics (First and Second Laws of Thermodynamics, Kooijman DEB reserve-structure dynamics, Brown et al. MTE allometry, Sterner & Elser C:N:P stoichiometry, Stommel thermohaline circulation, Howard-Kerby stream power erosion) that apply unconditionally across all planets and epochs—**Tier 2 (Type B)** engines formalize **context-dependent sociological, institutional, technological, capital-intensive, or geopolitical mechanisms**.

Per **`AGENTS.md §8.2, §11.3, §12.4, and §13`**:
1. **Strict 1-to-1 Bijection Between Catalog, UI Checkboxes, and Java Classes**:
   Every single engine documented in this catalog and exposed in `ScenarioEngineCatalog.getOptionalEngines()` corresponds **strictly 1-to-1** to an existing, executable Java class in `org.ether.society.engines.tier2.theories`, `org.ether.society.engines.tier2.historical`, or optional anthropogenic modules in `org.ether.society.engines.tier1` (**86 verified Type B engines in total**).
   - Permanent Tier 1 biophysical conservation laws (`DeforestationErosionEngine`, `BioMolecularEpidemiologyEngine`, `EntropicMetalDissipationEngine`, `MegafaunaEcosystemEngine`) are documented in `ScenarioEngineCatalog.getCoreEngines()` and execute unconditionally in Tier 1 passes.
   - Deprecated speculative or duplicate alias classes (`PsychohistoryPureEngine`, `KardashevPureEngine`, `TechnologicalSingularityEngine`, `AiAutonomousRegulationPureEngine`, `AutoRegulationPureEngine`, `FertileCrescentSalinizationEngine`) have been permanently removed from the codebase and UI catalogs.
2. **Full Deep-Time Horizon Coverage ($-3\,000\,000\text{ BP}$ to Post-$2025\text{ CE}$)**:
   In accordance with `AGENTS.md §8.2`, Ether supports deep-time simulation horizons extending back to **$-3\,000\,000\text{ BP}$** (Plio-Pleistocene / Lower Paleolithic hominin evolution, Oldowan/Acheulean foraging, kin selection, and cumulative cultural transmission).
3. **Prohibition of Artificial Cross-Epoch Overfitting**:
   A Type B engine must **never** be forced to operate outside its historical or structural domain via hidden internal sigmoid gates (`if (kpc < 500) return;`), calendar hacks (`if (year < 1800)`), or artificial parameter distortions.
4. **Default Unchecking Outside Validity Domain (`false` by Default)**:
   When a scenario is initialized for a planet $P$ and start year $t_0$ via `AutoEpochScenarioGenerator` (`AutoEpochScenarioHelper.calibrateTypeBEngines(planetKey, year)`), any Type B engine whose spatiotemporal, technological, capital, or geopolitical prerequisites are not met at $(P, t_0)$ is **explicitly unchecked (`false`) by default**.
